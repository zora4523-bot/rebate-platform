# 发布制品扫描

`detect/index.ts` 提供 QA-09b 的读取、检测与扫描函数；`compare/index.ts`
提供 QA-09a 的清单比对。命令行入口与流水线接入属于后续任务。

## 调用接口

- `readArtifact(path)`：返回 `{ entries, errors }`。文件支持 `.ipa`、`.apk`、
  `.aab`、`.hap`、`.app`，目录递归读取所有普通文件（包括隐藏文件）。
  条目路径相对制品根，用 `/` 分隔，返回顺序按路径排序。
- `detectSecrets(file, content, options?)`：接收字符串或字节，返回 `ScanHit[]`。
  `file` 原样保留；行号从 1 开始。损坏的结构化编码或无效阈值会抛错，
  调用方应按扫描失败处理。此函数也接受任意二进制片段：资源表按 ResTable
  类型头识别，其余片段仍检测可读字符串；完整制品应调用 `scanArtifact`，它对
  `resources.arsc` 强制解析，即使类型头损坏也不能回退后放行。
- `scanArtifact({ path, platform, manifestYaml, approvals, options? })`：读取并检测，
  调用 `compareHits`，返回命中、比对报告、读取错误、退出码与 `passed`。
  清单原文及批准记录由调用方从可信来源提供，不在本模块读取批准文件。
- `defaultDetectOptions()`、`shannonEntropy(value)`：默认阈值和香农熵计算。
  默认长度下限为 20，熵下限为 3.5 bit/字符；可分别覆盖，边界取等号。

`.ipa` 对应 `ios`，`.apk` / `.aab` 对应 `android`，`.hap` / `.app`
对应 `harmony`，目录只对应 `h5` / `admin`。读取失败、端不匹配或参数无效时
整体退出码为 2；清单无效时也为 2；其余情况下沿用比对报告的 0（通过）或
1（阻断）。有错误时仍列出已读到的命中并进行比对，不能只看部分比对报告放行。

## 读取边界

ZIP 仅在内存解压，不落盘、不调用外部命令。支持 stored、deflate 和数据描述符，
以中央目录定位并校验本地头、解压长度和 CRC。包内 `.ipa`、`.app`、`.hap`、
`.hsp`、`.apk`、`.aab`、`.jar`、`.aar`、`.zip` 继续解包，嵌套路径用
`内层包路径/文件路径` 表示；目录里的这些包也继续解包。加密、ZIP64、分卷、
不支持的压缩方式、非法路径、重复路径、符号链接和特殊文件均记为读取错误。

扫描对象应是已经构建完成、不再变化的制品。单文件（含压缩包）上限 256 MiB，
累计读取及解压上限 1 GiB，条目与目录预算共 100,000 个；嵌套包最多 16 层、
目录最多 128 层。超限阻断，不跳过后放行；大型制品需要另行调整预算后验证。

普通字节按 latin1 检测，并补充提取无 BOM 的 UTF-16LE 可打印字符串；带 BOM
的 UTF-16LE / UTF-16BE 按解码文本计算行号。二进制 plist 校验偏移、引用和
对象边界，解析键值后检测，Data 的可读字节与 base64 视图、数组元素都保留父字段名。
二进制 Android XML（AXML）解析 UTF-8 / UTF-16 字符串池与元素属性，恢复
`name` / `value` 关联（包括 typed string 引用）；损坏的 XML 容器按读取失败阻断。
XML 文件的二进制 XML 类型标识用于识别截断容器，其他二进制中的相似片段仍按普通字节检测。
`resources.arsc` 解析全局值字符串池、各包的键名池以及 type 条目的字符串引用，
恢复字段后检测，避免短盐因键值分离而漏报。支持 UTF-8 / UTF-16 池、普通 / 稀疏 /
16 位偏移索引、紧凑条目及复合条目的字符串值；未引用的池字符串也检测。
文件类资源（drawable、layout、mipmap、anim、xml、raw、font、menu、color 文件等）
的 `res/…` 路径取值只按孤立字符串检测，不配资源键名（如 `avd_hide_password`
不当作口令字段）。`TYPE_REFERENCE` / `TYPE_DYNAMIC_REFERENCE` 按资源 ID 解析引用链
（各配置都算，最多 8 跳，防环），以引用方的字段名检测最终取值；签名材料字段的引用
指向本表之外、成环或超过深度时按读取失败阻断。样式（style）与属性定义（attr）的条目项
引用常指向框架资源，解析结果只按孤立字符串检测、不配键名，也不因解析不了而阻断。
块边界、池长度、索引、条目长度和遍历预算不合法时，或遇到不支持的块及缺少本包
字符串池的继承包时，按读取失败阻断。格式依据
[Android ResourceTypes.h](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/libs/androidfw/include/androidfw/ResourceTypes.h)。
二进制 plist / AXML / resources.arsc 的行号是解析视图中的行号；
无 BOM 字符串池的行号是提取字符串内的行号，不能当作二进制字节偏移。

## 规则与报告

规则按私钥、请求签名材料、服务端密钥、阿里云 AccessKey ID、带口令 URL、
其他凭据字段、高熵串的顺序处理重叠范围。签名材料按字段语义检测，任何非空
取值都报；盐的轮数、长度等算法参数除外。字段名按点号、下划线、连字符与驼峰边界
切分后匹配完整词元，忽略 `this.`、`window.` 等对象前缀，不把 `alternate` 当作盐。
带引号的字面值与独立配置行照常检测；JavaScript 冒号或等号后的裸变量、null、数字
或表达式不当作材料值，读取裸值不会跨过逗号、分号等边界吞掉后续字段。
已知配置文件及整份纯 `key=value` 文本保留值里的标点，包括 YAML 盐值中的逗号，
与冻结属性测试的配置口径一致；格式串中的 `%s` 等占位符不算取值。
二进制（原生库、dex 等，前端代码与 JSON 除外）中提取出的独立可打印串，所在文本块
至少一端是 NUL 或其他不可打印字节时，按配置逐行判定：整行只有一个 `key=value` 时
取值到行尾；整行是 `k=v,k=v` / `k=v&k=v` 键值列表时取值在分隔符处截止；
其余代码表达式仍按上面的 JavaScript 口径处理，不吞后续字段。
无 PEM 头的 base64 私钥通过 DER 私钥版本字段及后继结构识别（含 SEC1 EC），
SPKI 公钥不按私钥升级。规则只描述形状，不保存任何真实密钥值。
公钥块及 URL 的高熵正文合并成整块命中，交给 QA-09a 比对。

前五类命中标记 `never_accepted`；其他凭据字段和高熵命中由比对模块结合清单
判断。扫描器不写日志；`hits.match` 含命中原文，调用方应对报告输出脱敏，
不要直接把原文写入公开 CI 日志或告警。

共用类型位于 `detect/types.ts`，子模块不回引入口。候选区间排序后按规则优先级
线性合并，行号查预计算的换行位置；ZIP 区间排序后检查相邻重叠。

本段遵循冻结规则测试定义的静态检测口径，不声称识别任意混淆、运行时拼接或
加密后隐藏的秘密。制品扫描结果须由编排者在隔离容器运行
`test/spec/release-scan/detect/**` 验证；实现会话仅执行类型检查与 lint。
