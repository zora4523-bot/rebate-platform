# AGENTS.md（apps/api/src/modules/feedback）

商品反馈模块：用户或游客对一件商品提交反馈（原因、返利、说明），只写本模块自己的表。

## 归属与边界

- 本模块不涉资金与归属；风险级与分工以根目录 AGENTS.md 的分工表为准（由 `ops/risk-map.yaml` 生成）。
- 只装 api 入口；不进 worker，不设定时或留存删除任务（保管期限待法务确认，见 BR-ID-30）。
- 读别的模块只经它们公开的只读端口（链接是否存在且属本 app、用户注销状态），不直接读写别的模块的表。
- 注销删除只经 identity 的注销清理端口（BR-ID-28）：删除该用户名下的反馈，游客记录保留。

## 写入规则

- 检查顺序以契约 `submitProductFeedback` 与任务书为准：平台幂等、功能开关、链接核验、每设备每日上限，再写入。
- 登录用户提交要与注销清理串行：同一事务里先锁该用户行、读注销状态，注销已开始的按游客记录写。
- 每设备每日计数在同一事务内加锁后再数，并发下也不超限；会计日只用 `packages/domain` 的函数，时间只读注入的 `Clock`。
- 签名设备必须属于本 app。
- 配置键的取值与默认值以配置登记为准，本文件不写数值。

## 测试

- 规则测试在 `test/spec/feedback/product-feedback/`，由规则测试作者编写，实现者不改。
- 本模块单元测试不连库。
