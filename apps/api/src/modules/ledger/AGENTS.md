# apps/api/src/modules/ledger（资金：账本）

账户（每个用户一个余额账户）、记账凭证、分录、余额缓存与日终校验。只有本模块改余额。无 HTTP 入口；只读出口另由任务加入（供收益看板与只读收益工具使用）。

## 硬规则

1. 复式记账：每张凭证至少两条分录、借贷合计为零；分录只插入，更正只靠红冲凭证。
2. 余额只由本模块在同一事务内随分录更新；记账前按账户 ID 升序加行锁。
3. 幂等落在凭证唯一键上；重放同一业务事件返回同一结果、不重复记账。
4. 金额只经 `@couli/money`，账务纯函数在 `@couli/domain`；本模块不自写取整或换算。
5. 时间只读注入的 `Clock`；会计日与结算月只用 `@couli/domain` 的函数，不用 SQL 时钟。
6. 只读写本模块的表；别的模块的数据只经对方 `index.ts` 导出的端口。
7. 日志只用 pino，不打金额以外的个人信息。
